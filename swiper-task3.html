2 · 超纲能力：缩略图画廊 + 键盘控制 参考 310-thumbs-gallery-loop.html

官方示例的写法要点：两个轮播实例——小轮播 #whSwThumbs 当缩略图条，主轮播 #whSwGallery 用 thumbs: { swiper: … } 与它联动；缩略图用 loop: true + slidesPerView: 4 + freeMode 让 10 张图可以横向自由滑动。课堂没讲的 keyboard 能力也加在这里：按 ← → 就能切换。

// ① 先建缩略图小轮播 var wh_thumbs = new Swiper("#whSwThumbs", { loop: true, spaceBetween: 10, slidesPerView: 4, freeMode: true, watchSlidesProgress: true, }); // ② 再建主轮播，并把小轮播交给它 new Swiper("#whSwGallery", { loop: true, spaceBetween: 10, navigation: { nextEl: ".wh_next", prevEl: ".wh_prev" }, keyboard: { enabled: true, onlyInViewport: true }, // 课堂未讲能力 thumbs: { swiper: wh_thumbs }, // 主图与缩略图联动 });

键盘控制：点一下主图区域后按 ← 上一张 / → 下一张；onlyInViewport: true 保证轮播滚出屏幕后按键不再误触发。

两个实例为什么必须这样建

参数作用
thumbs.swiper把缩略图实例交给主轮播，主图切换时缩略图同步高亮（swiper-slide-thumb-active）
slidesPerView: 4缩略图条一次露出 4 张，点击任意张主图立刻跳过去
freeMode + watchSlidesProgress缩略图可自由滑动、不强制吸附，同时把滑动进度同步给主轮播
keyboard开启键盘方向键切换；onlyInViewport 限制只在轮播可见时响应

4 · 答辩四连问

这段代码什么意思？
先建缩略图小轮播 #whSwThumbs（loop 循环、slidesPerView: 4 一次露 4 张、freeMode 自由滑动、watchSlidesProgress 输出滑动进度），再用 thumbs: { swiper: wh_thumbs } 把它交给主轮播 #whSwGallery，主图切换时缩略图自动高亮、点缩略图主图自动跳转；keyboard 让方向键也能切换。
AI 第一次给的哪里不对、你改了什么？
第一版只初始化了主轮播，没有缩略图实例，也没有 thumbs 绑定，结果缩略图点了完全没反应、主图切换时缩略图不高亮。我补建了小轮播实例并加上 thumbs.swiper，联动才成立。
新参数的作用？
thumbs.swiper = 绑定缩略图实例；slidesPerView: 4 = 缩略图条一次露出 4 张；freeMode = 缩略图可自由滑动不吸附；watchSlidesProgress = 把滑动进度同步给对方；keyboard.onlyInViewport = 只在轮播可见时响应方向键。
现场把 delay 改成指定值并解释预期变化
当前 delay 为 3200 毫秒；改成 1500 自动翻页明显变快，改成 6000 则更慢。若删掉 autoplay，就只能靠缩略图点击、左右按钮或键盘方向键切换。
