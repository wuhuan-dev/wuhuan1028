0 · 需求拆解 四条硬性需求

编号需求原文对应参数

1 · 第一轮提示词与 AI 回答

我的提示词（原文）

写一个 Swiper 初始化配置，作用在 id 为 #wySw4 的轮播上：不要循环，3.2 秒自动翻页，分页器可以点击，效果用 cube。

AI 第一轮回答

第一轮 · 有遗漏
new Swiper("#wySw4", { speed: 500, effect: "cube", autoplay: { delay: 3200, }, pagination: { el: undefined, clickable: true, }, });

判定：① 没写 loop: false，不循环只是"默认值"，语义不明确；② autoplay 缺 disableOnInteraction: false，拖动后自动播放会停；③ pagination 没给 el，圆点不会出现。三个需求没被真正满足。

2 · 第二轮提示词与 AI 回答

我的提示词（逐条补齐）

在你上一版基础上修正三点：1）必须显式写 loop: false，明确不循环；2）autoplay 里加 disableOnInteraction: false，保证用户手动拖动之后自动播放继续；3）pagination 必须写 el: "#wyPag4"，否则圆点不显示，clickable 保留 true。其余保持不变。

AI 第二轮回答

第二轮 · 可运行
new Swiper("#wySw4", { loop: false, speed: 800, effect: "cube", autoplay: { delay: 3200, disableOnInteraction: false, }, pagination: { el: "#wyPag4", clickable: true, }, });

关键体会：第一轮属于"许愿式提示词"，只说了目标没说约束；第二轮把每一处遗漏写成"必须 + 具体参数名 + 不满足会怎样"，AI 才给出可用配置。

6 · 答辩准备

你的第一版提示词漏掉了哪个需求？
严格说不是"漏写需求"，而是三个需求只写了目标没写约束：没显式关闭 loop、没写拖动后继续播放、分页器没给选择器，结果 AI 输出看似合理但功能不达预期。
你是怎么在第二轮里"说清楚"的？
把每条需求拆成"必须做什么 + 对应参数 + 不做的后果"三部分，例如"pagination 必须写 el: #wyPag4，否则圆点不显示"，AI 就无法忽略。
AI 第一次给的代码错在哪？
三处：loop 未显式关闭；autoplay 缺 disableOnInteraction: false；pagination 的 el 为 undefined，圆点根本不渲染。
如果现场把 delay 改成 1500 会怎样？
自动翻页间隔从 3.2 秒缩短到 1.5 秒，切换更频繁；单位是毫秒。
课堂未讲的 keyboard 能力怎么加？
配置里加 keyboard: { enabled: true, onlyInViewport: true }：先点一下轮播让它获得焦点，再按 ← / → 即可切换；onlyInViewport 保证轮播滚出屏幕后按键不再响应，避免和页面上下滚动冲突。
