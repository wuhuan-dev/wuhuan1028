    第四部分：扩展挑战（15分加分）

    实现左下角回到顶部按钮（纯CSS，无JS）：

    项目说明
    实现思路使用 position: fixed 定位在视口左下角，通过 <a href="#top-anchor"> 配合页面顶部的 id="top-anchor" 实现跳转。
    效果预览请直接查看页面左下角的蓝色渐变圆形按钮。
    实现代码：
    .back-to-top {
    position: fixed; bottom: 20px; left: 20px;
    width: 50px; height: 50px; border-radius: 50%;
    background: linear-gradient(135deg,#409eff,#7b5cff); color: #fff;
    display: flex; align-items: center; justify-content: center;
    opacity: 0.6; z-index: 999; transition: all 0.3s;
}
.back-to-top:hover { opacity: 1; transform: scale(1.1); }
