任务一 · 提示词工程师 让 AI 生成 #wySw4 的配置

需求原文四条：① 无需循环；② 3.2 秒自动翻页且手动操作后不停止；③ 圆点分页器可点击；④ 初始效果为 cube。

第一轮提示词（我的原文）

写一个 Swiper 初始化配置，作用在 id 为 #wySw4 的轮播上：不要循环，3.2 秒自动翻页，分页器可以点击，效果用 cube。

AI 第一轮回答

第一轮 · 有遗漏
new Swiper("#wySw4", { speed: 500, effect: "cube", autoplay: { delay: 3200, }, pagination: { el: undefined, clickable: true, }, });

问题：① 没有关闭 loop（Swiper 默认虽不循环，但没写 loop: false，语义不明确）；② autoplay 少了 disableOnInteraction: false，用户一拖动自动播放就停了，不满足"手动操作后不停止"；③ 分页器没给 el 选择器，圆点根本不会出现。

第二轮提示词（补清楚的三处）

在你上一版基础上修正三点：1）必须显式写 loop: false，明确不循环；2）autoplay 里加 disableOnInteraction: false，保证用户手动拖动之后自动播放继续，不要停；3）pagination 必须写 el: "#wyPag4"，否则圆点不显示，clickable 保留 true。其余保持不变。

AI 第二轮回答

第二轮 · 可运行
new Swiper("#wySw4", { loop: false, speed: 800, effect: "cube", autoplay: { delay: 3200, disableOnInteraction: false, }, pagination: { el: "#wyPag4", clickable: true, }, });

粘贴验证（下面是真实运行的同一份配置）

天宫空间站 · 第 1 张
复兴号动车组 · 第 2 张
C919 大飞机 · 第 3 张
爱达·魔都号 · 第 4 张
验证结论：cube 切换正常、圆点显示且可点；拖动第 4 张后再等待 3.2 秒仍会自动翻页（说明 disableOnInteraction: false 生效）；翻到最后一张不会回到第一张（loop: false 生效）。第一轮的三处遗漏在第二轮全部修正。

任务二 · creative 仿写 课堂没讲，自己查官方示例 + AI

参考官方示例 swiper/demo/257-effect-creative.html，读懂 creativeEffect 的 transform 写法，在演示四新增第 7 个按钮「creative 自定义」。

实施的关键配置

creativeEffect: { prev: { // 离场的那一张 translate: ["-80%", 0, -300], // 左移 80% + 沿 Z 轴后退 300px scale: 0.85, // 缩小到 85% rotate: [0, 0, -15], // 逆时针倾斜 15 度（Z 轴） shadow: true, }, next: { // 进场的那一张 translate: ["120%", 0, 0], // 从右侧 120% 处滑入 scale: 1.15, // 放大到 115% shadow: true, }, }

我用自己的话总结：prev / next 的 transform 各控制什么？

prev
控制"即将离开/被推到后面"的那张幻灯片：translate 决定它往哪边退、退多远；rotate 决定倾斜角度；scale 决定缩小还是放大。数值用负数表示往左、往屏幕里退。
next
控制"即将进入/被拉到前面"的那张幻灯片：translate 决定它从哪个方向、多远的位置滑进来；scale 决定它入场时是放大还是缩小。

答辩问题准备

transform 里的百分号是相对谁的？
相对幻灯片自身的宽度（Swiper 内部换算成容器宽度的百分比），不是相对屏幕或父元素。所以 100% 就等于"整整一张幻灯片的宽度"。translate 的第三个值（z 值）才是像素单位。
改一个数值让卡片转 20 度试试？
把 prev 的 rotate: [0, 0, -15] 改成 [0, 0, -20] 即逆时针 20 度；改成正数 20 则是顺时针 20 度。

② 超纲控件：keyboard 键盘控制 + mousewheel 滚轮控制

keyboard: { enabled: true, // 开启键盘操作 onlyInViewport: true, // 只有轮播在视口内时才响应，避免整页滚动时误触 }, mousewheel: { enabled: true, forceToAxis: true, // 只响应水平滚动，避免和页面垂直滚动打架 },

答辩问题准备

这段代码什么意思？
keyboard 让左右方向键可以切换幻灯片；mousewheel 让鼠标滚轮在轮播上滚动时也能切换。onlyInViewport 与 forceToAxis 都是"防误触"参数，避免和页面本身的滚动冲突。
AI 第一次给的哪里不对、你改了什么？
第一版只写了 keyboard: true 与 mousewheel: true，我在页面上试的时候键盘没反应——Swiper 11 里这两项要写成对象并带 enabled: true，改成对象写法后才生效。
新参数的作用？
onlyInViewport：轮播不在视口内时不响应键盘；forceToAxis：滚轮只沿轮播的主轴方向滚动才切换。
现场把 delay 改成指定值并解释预期变化
例如把 delay: 3200 改成 1500，自动翻页变快，大约 1.5 秒换一张；改成 6000 则 6 秒才换一张。delay 的单位是毫秒。
