课堂上只讲了 6 种 effect，Swiper 其实还有第 7 种 creative（自定义变换）。本页在演示四新增第 7 个按钮，并把它调成"电影选片墙"。

1 · 源文件与思路 参考 257-effect-creative.html

官方示例 swiper/demo/257-effect-creative.html 只给了最简写法：effect: "creative" 配合 creativeEffect。要让画面"像电影选片墙"，需要分别定义 prev（离场帧）和 next（进场帧）的位移、缩放与倾斜。

creativeEffect: { prev: { translate: ["-80%", 0, -300], // 左移 80%、Z 轴后退 300px scale: 0.85, // 缩小到 85% rotate: [0, 0, -15], // 逆时针倾斜 15 度 shadow: true, }, next: { translate: ["120%", 0, 0], // 从右侧 120% 处滑入 scale: 1.15, // 放大到 115% shadow: true, }, }

3 · 用自己的话说清 prev / next

配置项控制什么本页取值与效果
prev.translate离场幻灯片的位置（x / y / z）[-80%, 0, -300]：向左退、并向屏幕深处退
prev.scale离场幻灯片的缩放0.85：缩小到 85%，产生景深
prev.rotate离场幻灯片的 3D 倾斜[0, 0, -15]：绕 Z 轴逆时针 15 度
next.translate进场幻灯片从哪来、多远[120%, 0, 0]：从右侧画面外滑入
next.scale进场幻灯片的缩放1.15：放大到 115%，形成"推近"的冲击
shadow是否为幻灯片叠加投影true：增强层次，像选片台上的卡片

4 · 与 AI 的关键对话记录

轮次我的提示词AI 的回应与我的处理
第 1 轮 "参考 257-effect-creative.html，给第 7 个按钮加 creative 电影选片墙效果" AI 只写了 effect: "creative"，没有 creativeEffect，切换看起来接近普通淡入；我判定不合格
第 2 轮 "上一张要缩小左移并带角度，下一张要放大右移进场；把 prev / next 的 translate、scale、rotate 具体数值写出来" AI 补出 prev.translate: ["-80%",0,-300]、scale: 0.85、rotate: [0,0,-15]，以及 next.translate: ["120%",0,0]、scale: 1.15，效果达标
第 3 轮 "再加一个课堂没讲的能力：键盘方向键也能切换，并且只在轮播可见时响应" AI 给出 keyboard: { enabled: true, onlyInViewport: true }；onlyInViewport 避免页面滚动时方向键误触发

5 · 答辩准备

transform 里的百分号是相对谁的？
相对幻灯片自身（等价于容器宽度）的百分比，不是屏幕也不是父元素；100% 就是"整整一张幻灯片的宽度"。translate 的第三个值（z 轴）是像素单位。
改一个数值让卡片转 20 度试试？
把 prev.rotate: [0, 0, -15] 改成 [0, 0, -20] 为逆时针 20 度；写成 [0, 0, 20] 则是顺时针 20 度。负号决定方向，绝对值决定角度。
为什么动态换 effect 要 destroy 再 new？
Swiper 在初始化时按 effect 写入 DOM 结构与 CSS transform，运行中只改 params.effect 不会重建这些结构，所以必须销毁旧实例后按新配置重建。
课堂未讲的 keyboard 能力怎么加？
配置里加 keyboard: { enabled: true, onlyInViewport: true }：点一下轮播获得焦点后按 ← / → 切换；onlyInViewport 保证轮播滚出视口后按键不再响应，避免与页面滚动冲突。
